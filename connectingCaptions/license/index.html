What you are buying

GPLv3 still lets a firm run the free zip. A commercial license is the paper IT can file: a named organization, an offline activation key, and a person who answers when something breaks.

  • A named organization license and an air-gapped activation key.
  • The same security mailbox, with an optional written SLA.
  • A Licensed to {org} line in the app so procurement can see the Mac is covered.

What IT usually asks

  • How does this monetize? A named license, and support if you want it. Transcripts, voiceprints, and training data are not part of the sale.
  • Does voice leave this Mac? It stays on the Mac unless someone turns on a cloud speech model. Theater doesn’t send anything home.
  • Who fixes a break? Security reports get a reply within 7 days. A paid license can add a written SLA.

How a key works

  • Personal and evaluation: the GPLv3 zip. Theater Listen stays unlocked.
  • Work: a named organization license if IT or legal need a vendor, a signed license on the Mac, or an SLA.
  • Activation is an offline signed key. It doesn’t call home.

Paste the key in the app → Settings → General. Listen does not lock. The key only replaces the work notice with Licensed to your organization.

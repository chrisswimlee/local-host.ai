The idea

Hey. localhost.

Everyone’s seen it if you’ve ever built anything. That address on your machine. The one that means here, not someone else’s server.

This is supposed to be yours. You own this code. You’re supposed to own these agents. You host them. You run them. Everything on your own computer.

The local agent

        

          

            01
            
On-device mind

            

              The agent reasons on your silicon. Models stay on the machine —
              a rented GPU is never the default.
            

          

          

            02
            
Local memory

            

              Notes, context, and history live on disk. The agent remembers
              with you, not in someone else’s cloud.
            

          

          

            03
            
Open skills

            

              Tools the agent uses are files you can read, fork, and change.
              No black box between you and the work.
            

          

          

            04
            
Offline by default

            

              Home is 127.0.0.1. The network is a choice you make — not a
              requirement to wake the agent.

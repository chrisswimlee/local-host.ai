What IT usually asks

  • How does this monetize? Named license $240 per Mac per year, $120 for schools, five Macs minimum. Written SLA $3,000 per organization per year. Installer package $2,500 once. Transcripts, voiceprints, and training data are not part of the sale.
  • Does voice leave this Mac? No, by default. Speech and translation run on the device. Voice stays on the Mac unless someone turns on a cloud speech model. Theater doesn’t send anything home. No account, no telemetry.
  • Who fixes a break? Security reports get a reply within 7 days. The security policy covers scope and the unsandboxed build. A paid license can add a written SLA.

How a key works

  • Personal use: download the zip. Listen does not need a key until the App Store app is available.
  • Work: a named license when an organization owns the Mac. Five Macs minimum.
  • The key is checked on the Mac. It does not call home. The current personal download does not need one.

Paste the key in Settings → General. A personal key says Personal license. A work key says Licensed to your organization.

Security

The zip is notarized. The app is unsandboxed, with Hardened Runtime on. Theater needs the microphone. Typing into another app needs Accessibility. Library validation stays off so the Whisper framework can load. Scope and how to report a problem are in the security policy. Reports go to support@local-host.ai and get a reply within 7 days. security.txt points at the same contact.

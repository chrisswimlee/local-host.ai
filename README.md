# local-host.ai

Software that stays on the Mac.

[Connecting Captions](https://local-host.ai/connectingCaptions) is live: on-device captions for a presentation, a bilingual room, or any conversation that needs a translation. Speech and translation run on the device. Voice stays on the machine unless you turn on a cloud speech model.

A local agent is next. It thinks on-device, remembers on disk, and runs skills you can open.

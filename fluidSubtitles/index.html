fluidSubtitles

Live captions on a Mac. Speak Korean, English, Thai, or Japanese. A translation or a caption shows up on screen.

Korean · English · Thai · Japanese

Download 1.6.12 For work: Request a commercial license GitHub local-host.ai

Install

macOS 15 or later, Apple Silicon. The zip is notarized.

Download fluidsubtitles-1.6.12.zip
  1. Unzip it and drag fluidSubtitles to Applications.
  2. Open Theater, allow the microphone, then press Listen.

Homebrew

brew tap chrisswimlee/fluidsubtitles brew trust chrisswimlee/fluidsubtitles brew install --cask fluidsubtitles

What it is

  • A Theater window over slides. It can hide from Zoom and screen share.
  • On-device Apple Translation. It’s a branch of FluidVoice.
  • Voice stays on this Mac. A cloud speech model is something you turn on.

What you need

  • macOS 15 or later. Apple Silicon.
  • Microphone for Listen. Accessibility only if you type into another app.

For work

Personal use stays free. If IT or legal need a named license or an SLA, request a commercial license.

  • How does this monetize? A named license, and support if you want it. Transcripts, voiceprints, and training data are not part of the sale.
  • Does voice leave this Mac? It stays on the Mac unless someone turns on a cloud speech model. Theater doesn’t send anything home.
  • Who fixes a break? Security reports get a reply within 7 days. A paid license can add a written SLA.
